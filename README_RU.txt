DATABOT — ПОЛНАЯ ЛОКАЛЬНАЯ УЧЕБНАЯ СБОРКА

ЗАПУСК НА WINDOWS (у тебя уже создан .venv):
1) Открой PowerShell в папке проекта.
2) Если окружение ещё не создано:
   py -3.9 -m venv .venv
3) Активируй:
   .\.venv\Scripts\Activate.ps1
4) Установи зависимости:
   python -m pip install -r requirements.txt
5) Запусти:
   python -m streamlit run app.py
Можно также дважды нажать run_databot.bat после установки зависимостей.

ВАЖНО ДЛЯ ТВОЕЙ ТЕКУЩЕЙ ПАПКИ:
Ранее ты уже установил библиотеки в .venv. Если распаковываешь ЭТОТ архив в новую папку,
создай там отдельное окружение и повтори установку. Не копируй .venv из старого проекта.

GPT И ПОИСК:
- Без ключа приложение работает в локальном режиме: учебные разделы, SQLite-конструктор,
  визуализация, сценарные ветвления и тест.
- Для GPT нужен отдельный OpenAI API key и оплачиваемый API-биллинг.
- Создай копию .env.example с именем .env и вставь ключ после OPENAI_API_KEY=.
- Никогда не отправляй ключ в переписку и не публикуй .env.
- При включённом GPT ответы по теме идут через модель и web_search_preview.
- Подписка ChatGPT не включает оплату API.

ЧТО РЕАЛИЗОВАНО:
1. Чат и ограничение тематики (topic / neutral / other).
2. Учебные разделы.
3. Динамическая смена пути к SQLite-файлу через интерфейс.
4. Загрузка/перенос SQLite-файла в проект.
5. Просмотр таблиц и построение графиков.
6. Перечень компонентов и свойств (примеры Windows Forms/.NET).
7. Сценарные ветвления с повторной попыткой и возвратом.
8. Итоговый тест, локальное сохранение результатов в CSV.

ОГРАНИЧЕНИЯ И ЧЕСТНОСТЬ:
- Настоящий Aimylogic-бот не может быть создан/опубликован из локального Python-проекта без входа
  в Aimylogic и создания проекта в аккаунте. В папке aimylogic лежит сценарный план для ручного переноса.
- Настоящие Google Forms и Google Sheets требуют Google-аккаунта и авторизации/настройки доступа.
  Локальная таблица CSV не является Google Sheets. Инструкция и структура полей находятся в docs.
- Реальное подключение реализовано для SQLite. Серверные MySQL/PostgreSQL здесь описаны концептуально;
  для них требуются драйверы, сервер и корректные параметры подключения.
- Названия свойств компонентов зависят от технологии. В приложении перечислены примеры Windows Forms/.NET.
